Climate Risk & TARP Tool

This tool helps generate a project-specific Trigger Action Response Plan (TARP). You tell it your project's state, season, construction activity and site conditions, and it shows you the climate hazards that apply, the T1–T3 trigger thresholds, and the mitigation actions for each one.

Anyone on the project team who needs to look up or generate a TARP can use this html page.

Step 1: Get the tool onto your computer
- Go to the repository page.
- Click Download ZIP
- Find the downloaded ZIP file (usually in your Downloads folder)
- Extract it.
- You'll end up with a regular folder containing the tool's files.

Step 2: Open the tool
- Open the extracted folder
- Open the file called climate-risk-tarp.html

It will open automatically in your default web browser (Chrome, Edge, Safari, etc.).

Step 3: Use the tool
- Fill in the project details requested on screen: state/territory, season, construction activity, and site conditions
- The tool will display:
- The climate hazards that apply to your project
- The T1, T2 and T3 trigger thresholds for each hazard
- The mitigation action required at each level
